APPLE ATLAS — INSTALLATION

1. Décompressez apple-atlas-github.zip.
2. Ouvrez le dossier apple-atlas.
3. Déposez index.html à la racine de votre dépôt GitHub (au même niveau que les autres fichiers principaux).
4. Remplacez l'ancien index.html si GitHub vous le demande.
5. Validez les modifications (Commit changes).
6. Attendez le déploiement GitHub Pages ou Cloudflare Pages.

Le site utilise des images distantes hébergées sur des pages Apple et nécessite Internet.
Les liens d'achat ouvrent les pages Apple Store correspondantes.
Apple Atlas est un projet indépendant, non affilié à Apple.
